# Topics

Focused, living records of continuing concerns live here.

Topic documents own current truth, accepted decisions, evidence, known gaps,
and recommended next work. Architecture and research documents own durable
system shape or historical investigation. Numbered tactical documents under
[`../tactical/`](../tactical/README.md) own bounded implementation slices and
execution records.

Create a focused sibling topic when two concerns can evolve independently.
Update the owning topic whenever implementation or new evidence changes its
status. Do not create a topic for every small standalone change.
