# Historical TypeScript Engine Backlog

Status: **archived.** This was the implementation backlog for the unpublished
Node/TypeScript CLI and engine. That source and release lane were retired in
[Tactical 013](tactical/013-retire-typescript-cli.md); unchecked items below
are not current commitments.

The completed keep-alive and range work survives as historical evidence and as
native Rust/Kotlin behavior tests. Compression, uploads, HTTPS, and related UI
work require explicit product decisions for each supported platform rather
than revival of the removed engine.

The original checklist remains available in Git history and the completed
implementation tacticals that linked here.
